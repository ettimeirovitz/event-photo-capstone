יומן הרצה - Run Log
1. הכנת סביבה והתקנות
node --version 
עבד בהצלחה, הגרסה המותקנת במחשב היא  v22.17.0.
npm install
עבד בהצלחה, הותקנו 210 חבילות, התקבלו אזהרות מערכת רגילות, אבל לא נדרשה שום התערבות או תיקון מיצדי 
2. הרצת בדיקות
npm test
עבד בהצלחה, המערכת הריצה את קובץ הבדיקות ואומת שכל 5 הבדיקות עברו בהצלחה, כולל אימות הרשאות הצלם והלקוחה.
3. בדיקת טיפוסים (Typecheck)
npm run typecheck
עבד ללא תקלות. הפקודה סיימה לרוץ ללא שגיאות בקוד.
4. הפעלת השרת
npm run dev
עבד בהצלחה. השרת הופעל ומאזין בכתובת http://localhost:3000.
סיכום ותקלות
מה עבד? כל הפקודות וההתקנות עברו בצורה חלקה בפעם הראשונה
מה לא עבד? לא נצפו שגיאות או קריסות של השרת
מה היה צריך לשנות/לתקן? לא היה צורך בשום תיקון, המערכת רצה כראוי מיד לאחר ביצוע ה-clone.
